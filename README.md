# ULTIMUNE | Journey Analytics（修正版・静的HTML）

現行版（https://github.com/amiyamura-a11y/ultimune-journey-analytics-site ）とは別に管理する修正版ダッシュボードです。`index.html` に正規化済みの個票を埋め込み、すべての集計をブラウザ内で再計算します。

- 公開URL: https://amiyamura-a11y.github.io/ultimune-journey-analytics-site-v2/
- 生成元: https://github.com/amiyamura-a11y/shiseido_customerjourney_utm の `v2` ブランチ（`backend/scripts/export_static_html.py`）
- 更新方法: 生成元で再生成した HTML を `index.html` として上書きし push する
